Q1: Why might we consider using Git?

Answer: We might consider using Git to show commit history, branch out to try new code, and go back to previous branches to make changes to the original code. This is useful for code that is collaborated and modified upon often.
In this class Git could be useful to show the process in which students made commits to code overtime, as well as for group projects where students need to collaborate on code.

Q2: What field could data science be applied to? Give an Example.

Answer: Data science could be applied to the medical field, for example gathering
statistics on patients who took a real pill and a placebo pill and comparing numerical pill reaction statistics between the two groups using data science.


Q3: What is the difference between Merging and Rebasing?

Answer: Merging links the histories of branches merging together with a visual branch split showing the history of the commits.
On the other hand, rebasing deletes commit history and replaces it with brand new commits for each commit in the original branch, resulting in a cleaner project history, which could potentially be risky for collaborative environments.
